
# 3D Warehouse Inventory Management System

A modern 3D Warehouse Inventory Management System designed to visualize warehouse operations, manage inventory, and monitor stock efficiently.

## 🚀 Features

- Interactive 3D Warehouse Visualization
- Inventory and Stock Management
- Product Tracking
- Warehouse Dashboard
- Real-Time Inventory Monitoring
- Responsive User Interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- TypeScript
- Vite
- Three.js
- Tailwind CSS
- Node.js
- Google Gemini API

## 💻 Run Locally

### Prerequisites
- Node.js
- npm
- Git

### 1. Clone the repository

```bash
git clone https://github.com/bharath56721/inventory-management-3d-warehouse.git
```

### 2. Navigate to the project folder

```bash
cd inventory-management-3d-warehouse
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Use your own valid API key. Never upload API keys to GitHub.

### 5. Run the application

```bash
npm run dev
```

### 6. Build for production

```bash
npm run build
```
